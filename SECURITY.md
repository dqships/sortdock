# Security policy

## Supported versions

Security fixes are made for the latest code on the default branch. Older builds
may not receive updates.

## Reporting a vulnerability

Please do not open a public issue for a possible security problem. Report it
privately by using [GitHub's private vulnerability reporting](https://github.com/dqships/sortdock/security/advisories/new).

Include a clear description, the affected version or commit, steps to reproduce
the problem, and any possible impact. Please give us time to investigate and
release a fix before sharing details publicly.

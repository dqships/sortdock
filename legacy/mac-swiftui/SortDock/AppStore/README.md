# SortDock Mac App Store release package

This directory contains reviewable App Store metadata, safe upload configuration, screenshot validation, and release evidence. It contains no credentials, certificates, provisioning profiles, Apple sessions, or personal files.

Run `python3 scripts/validate-metadata.py`, `scripts/validate-screenshots.sh`, and `scripts/validate-icons.sh` before upload. URLs use the verified SortDock production deployment at `https://sortdock.vercel.app`.

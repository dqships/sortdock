# App Review notes

SortDock is a menu-bar macOS utility. No login or demo account is required.

On first launch, setup asks the reviewer to choose a folder. A temporary test folder may be used instead of Downloads. Create a destination, add a keyword such as `invoice`, and save the rule. Place a harmless file named `invoice-test.pdf` in the selected watched folder. In Ask mode, the decision appears in SortDock’s menu-bar interface. Choose Move, Leave Here, Ask Later, or Choose Another Folder.

The Dock application appears only during setup or when the reviewer explicitly chooses Open SortDock. All file processing is local. Name collisions receive a safe new name such as `example (1).pdf`; no existing file is overwritten. Pause sorting from the menu bar and use Quit SortDock to stop the app.

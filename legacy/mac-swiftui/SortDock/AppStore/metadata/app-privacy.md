# App privacy

Native SortDock has no accounts, analytics, crash SDK, advertising SDK, tracking, support SDK, network telemetry, or third-party SDK that transmits personal data. It makes a short HTTPS request to Apple’s public App Store lookup service to compare the installed app version with the public listing. That request contains only SortDock’s bundle ID and does not send personal data, folder details, or file names. Its final native privacy response should be **No, we do not collect data from this app** after archive inspection confirms this remains true.

The website is separate and may process standard hosting request logs. Support emails are processed by email providers when a customer writes to support.

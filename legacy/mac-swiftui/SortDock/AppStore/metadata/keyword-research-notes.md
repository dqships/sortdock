# Keyword research notes

Source read: `/Users/starship/Downloads/keyword-rules.md`, modified 2026-08-20 11:41.

Applied rules:

- Choose phrases that describe the customer’s main outcome, not internal feature labels.
- Use distinct search phrasings and avoid broad filler, claims, competitors, and trademarks.
- Avoid wasting terms already covered by the listing name and subtitle unless an exact query needs it.
- Use comma-separated phrases with no spaces after commas and remain within 100 bytes.

The final title keeps the truthful primary query “Downloads Organizer.” The keyword field covers alternate customer language: download folder organizer, file sorter, file organizer, download cleanup, and automatic file sorting.
